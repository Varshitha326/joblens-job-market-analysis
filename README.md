# JobLens: Job Market Analysis

Analysis of job postings to find in-demand skills, salary trends,
and entry-level requirements, with ML model comparison.

## What it does
- Data collection and cleaning
- Skill, salary and experience analysis
- Model comparison
- Auto-generated report (Word) and deck (PowerPoint)

## How to run
pip install -r requirements.txt
python 05_reports\generate_report.py
